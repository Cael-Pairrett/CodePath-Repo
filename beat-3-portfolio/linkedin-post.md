I contributed to an open-source tool that lets people look up Bitcoin data from the command line. I added a short guide with eight ready-to-use examples that show real Bitcoin outputs, plus tests that check the examples stay correct.

The maintainer reviewed the work and asked for two small changes. I made both the next day, and the maintainer replied, "Thanks for the quick follow-up, both changes look good. Merging." The changes were merged into the project on November 10.

Anyone using the tool can now copy working examples instead of figuring them out on their own, and the tests help keep the guide from breaking later. I also learned how quickly responding to real feedback helps a contribution land.
